# نظام الموارد البشرية

- `admin/` لوحة الإدارة (HTML/CSS/JS بدون أدوات بناء)
- `supabase/schema.sql` الجداول والصلاحيات وتخزين المستندات

## التشغيل على Supabase
1. أنشئ مشروعًا على supabase.com.
2. SQL Editor ← الصق محتوى `supabase/schema.sql` ← Run.
3. Authentication ← Users ← Add user (فعّل Auto Confirm User).
4. شغّل: `update public.profiles set role = 'admin' where email = 'إيميلك';`
5. افتح `admin/js/config.js` وضع `supabaseUrl` و`supabaseKey` (anon key فقط).
6. ارفع على GitHub وافتح الموقع، وهيطلب تسجيل الدخول.

> المفتاح العام (anon) مصمم يكون ظاهر في الكود، والحماية الحقيقية من RLS في `schema.sql`.
> ممنوع وضع `service_role` في أي ملف.

## الملفات اللي بتتشغل في SQL Editor (بالترتيب)
1. `supabase/setup.sql`: الجداول والصلاحيات وحساب المدير.
2. `supabase/02-audit.sql`: سجل التعديلات (مرة واحدة بعد الأول).
3. `supabase/03-hardening.sql`: قيود تمنع التداخل والأخطاء (إجازات، حضور، أرقام قومية مكررة، مبالغ سالبة).
4. `supabase/04-payroll.sql`: قواعد الرواتب وإقفال الشهر بلقطة ثابتة (الاعتماد وإعادة الفتح للمدير فقط).
5. `supabase/05-loans.sql`: السلف بأقساط تتخصم تلقائيًا.
6. `supabase/06-leaves-termination.sql`: إنهاء الخدمة (تاريخ وسبب) وبيانات قرارات الإجازات.
7. `supabase/07-employee-app.sql`: الحضور بالموقع من السيرفر، موافقة المدير المباشر، قسايم الموظف.

## إعدادات لازم تتعمل من لوحة Supabase
- Authentication ← Sign In / Providers: عطّل **Allow new users to sign up** (الحسابات بتتضاف من المدير فقط).
- المكتبات (Supabase / Chart.js / SheetJS) متخزنة محليًا في `admin/vendor/` ومش بتتحمل من CDN خارجي.

## المزايا
- استيراد الموظفين من Excel/CSV (صفحة الموظفين ← استيراد Excel).
- سجل التعديلات (للمدير فقط) من قاعدة البيانات مباشرة.
- المستخدمون والصلاحيات (للمدير فقط): الدور وربط الحساب بالموظف.

- الرواتب: قواعد قابلة للتعديل بالكامل (بنود، أوفر تايم، تأخير وغياب، تأمينات، ضريبة، عطلات) مع معاينة حية، وإقفال شهري مع لقطة ثابتة.
- الرواتب (إضافات): قائمة فحص قبل الاعتماد، مقارنة بآخر شهر معتمد، سلف بأقساط، ملف تحويل بنكي، ملف محاسب (Excel)، وقسايم للطباعة أو PDF، ومعاينة أثر تغيير القواعد على الشركة كلها.
- الإجازات: أنواع وأرصدة وشروط قابلة للضبط (ترحيل، استحقاق شهري، زيادة بسنوات الخدمة، حد أقصى لمن في إجازة من القسم)، دورة موافقات بسبب رفض مكتوب، وتقويم للفريق.
- إنهاء الخدمة بدل الحذف (الحذف النهائي للمدير فقط بتأكيد الاسم)، وراتب جزئي تلقائي للتعيين والإنهاء في نص الشهر.

## تطبيق الموظفين (`/employee/`)
- بيتفتح من موبايل الموظف على رابط `.../employee/` وبيتثبّت على الشاشة (أندرويد: تثبيت التطبيق، آيفون: مشاركة ثم إضافة للشاشة الرئيسية).
- لازم HTTPS عشان تحديد الموقع يشتغل (GitHub Pages بيوفره).
- لإضافة موظف: Authentication ← Add user (Auto Confirm)، وبعدين من لوحة الإدارة ← المستخدمون اربط حسابه بملفه.
- مواقع العمل: لوحة الإدارة ← الحضور ← مواقع العمل. الفحص بيتم على السيرفر ومش ممكن يتجاوز من التطبيق.
- المدير المباشر بيظهر له تبويب "الفريق" تلقائيًا لما يكون ليه موظفين تابعين، وبيشوف فريقه بدون أي بيانات مالية.
